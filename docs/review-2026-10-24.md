## 已修复问题

| 模块 | 问题及影响 | 修复 |
| --- | --- | --- |
| 配置审计 | JSON、带引号的 YAML 键和环境配置格式可能漏检；全大写凭据被误认为变量名；无法读取的文件被忽略 | 支持结构化 JSON 属性及常见配置赋值格式，仅跳过明确引用和指向型键；超限或不可读时披露覆盖不全 |

| 压缩资源 | 完整解压之后才截断，压缩率高的文件可能大量占用内存 | 流式解压时执行明文预算；累计预算按 UTF-8 字节计算 |
| 注入正则 | 六条规则在长空白近似匹配上出现二次复杂度，阻塞协作式超时 | 重写歧义空白量词，规则集升级为 v5，增加隔离性能回归 |
| 扫描缓存 | 嵌套命中对象共享、截断状态串用、上下文边界碰撞；临时失败长时间复用 | 深复制命中项，明确编码缓存键，无法可靠编码的分类器上下文绕过缓存；不缓存不完整结果 |
| 分类器 | 超时仅停止等待，请求继续运行；非法置信度越界 | 传递可选第三参数中的取消信号；Ollama 使用合法默认置信度 |
| JSON 脱敏 | 根字符串遗漏；自定义规则覆盖内置规则；全局正则交替漏键；序列化钩子恢复原值 | 统一字符串通道，规则叠加，隔离正则状态，禁止复制可执行序列化钩子 |
| JSON 资源 | 循环与共享对象展开可能放大工作量；自定义正则阻塞宿主 | 循环立即遮蔽，设置节点与字符预算；工具自定义正则在可终止的工作线程内执行 |
| 日志 | 嵌套 PII、敏感键未脱敏；字段可覆盖审计元数据；禁用日志仍打开文件 | 递归脱敏、保护元数据、禁用时不创建流 |
| 供应链检查 | 同名插件多个版本被覆盖；畸形响应可能被当成无漏洞；正文解析未受超时约束 | 使用 npm bulk advisory API、发送全部版本、校验响应、覆盖整次请求超时 |
| 发布与依赖 | 分支名可绕过标签检查；npm 最低补丁版本检查不精确；开发依赖含已知漏洞 | 强制真实标签和提交匹配，按发布引用串行化，修正版本检查；锁定 zod 4.6.7 |

## 新增资源限制

- 自定义 JSON 键正则：最多 20 个、每个最多 200 字符；工作线程预算 2 秒，V8 老生代堆上限 64 MB。
- JSON 原文：最多 4,194,304 个 UTF-16 单元；遍历最多 100,000 个值；累计处理键/值字符最多 4,194,304。
- 深度默认 32，允许范围 0–256；普通字符串值默认处理前 1,000,000 个字符。
- 超过 JSON 总预算或自定义正则预算时，返回空结果及脱敏后的错误；调用方必须检查 `error`。
